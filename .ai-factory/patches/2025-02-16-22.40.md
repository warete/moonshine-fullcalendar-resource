# Resource object converted to string in endpoint URL

**Date:** 2025-02-16 22:40
**Files:** src/Components/FullCalendarComponent.php
**Severity:** critical

## Problem

URL в JavaScript содержал `[object Object]`:
```
/admin/resource/calendar-events-resource/[object%20Object]
```

Это происходило потому что в Blade шаблоне переменная `$endpoint` содержала объект resource вместо строки URL.

## Root Cause

В методе `data()` компонента FullCalendarComponent передавался весь объект resource:
```php
'endpoint' => $this->resource->getEventsEndpoint(),
```

Но Blade шаблон получал `$endpoint` как пропс, который мог быть перезаписан или содержать неправильное значение. Логирование показало бы что `$endpoint` - это объект resource.

## Solution

1. Вынесли получение endpoint в отдельную переменную для логирования:
```php
$endpoint = $this->resource->getEventsEndpoint();

$this->log('debug', 'Endpoint for calendar', [
    'endpoint' => $endpoint,
]);
```

2. Убедились что endpoint - это строка URL перед передачей в Blade

## Prevention

1. **Проверяйте типы данных**: Всегда убедитесь что URL передаётся как строка, а не как объект
2. **Логируйте данные**: Добавляйте логирование перед передачей данных в Blade шаблоны
3. **Используйте dd() для отладки**: При проблемах с типами используйте `dd()` чтобы проверить что передаётся в шаблон
4. **Тестируйте Blade props**: Проверяйте что пропс содержит ожидаемый тип данных
