# Alpine.js Component Not Registered

**Date:** 2025-02-16 22:25
**Files:** resources/views/components/full-calendar.blade.php, resources/js/full-calendar.js
**Severity:** critical

## Problem

```
Uncaught ReferenceError: fullCalendar is not defined
    at [Alpine] fullCalendar({...})
```

The Alpine.js component `fullCalendar` was not being registered when the Blade template tried to use it in `x-data`. The component threw a ReferenceError because the JavaScript code that registers it was wrapped in an IIFE by Vite and wasn't being executed at the right time.

## Root Cause

1. **Missing script tag**: The Blade template didn't include the compiled JavaScript file
2. **Timing issue**: The script was loaded with `defer` attribute, which delays execution until after DOM parsing
3. **IIFE scope**: Vite's IIFE output format wraps the code in a closure, which can cause timing issues with Alpine.js registration
4. **No x-cloak**: The component didn't have `x-cloak` directive to prevent flash of unstyled content before Alpine initializes

## Solution

### 1. Added script tag to Blade template

```php
@once
@push('scripts')
    <script src="{{ asset('vendor/moonshine-fullcalendar/js/full-calendar.js') }}"></script>
@endpush
@endonce
```

### 2. Removed defer attribute

Changed from `defer` to immediate loading to ensure the script executes before Alpine tries to use the component.

### 3. Added x-cloak directive

Added `x-cloak` to the container div to hide it until Alpine is ready:

```html
<div x-data="fullCalendar(...)" x-cloak>
```

### 4. Added debugging logs

Added console.log statements to track when:
- Script loads
- alpine:init event fires
- Component registration happens

```javascript
console.log('[FullCalendar] Script loaded, waiting for alpine:init');
console.log('[FullCalendar] Alpine:init event fired, registering component');
```

## Prevention

1. **Always check Alpine.js component registration**: When using custom Alpine components, verify they are registered before use
2. **Include script tags**: Ensure compiled JavaScript is included in the template that uses it
3. **Use x-cloak**: Always add `x-cloak` to Alpine components to prevent FOUC (Flash of Unstyled Content)
4. **Test with browser console**: Check console for registration errors when developing Alpine components
5. **Consider Vite format**: For packages, consider using ES modules instead of IIFE for better compatibility with Alpine.js
