# MoonShine.request не возвращает данные — нужен обычный fetch

**Date:** 2025-02-16 22:58
**Files:** resources/js/full-calendar.js
**Severity:** critical

## Problem

MoonShine.request не подходит для получения JSON-данных в FullCalendar, потому что эта функция:

1. **Не возвращает данные** — выполняет только побочные эффекты
2. **Предназначена для HTML-обновлений** — обновляет DOM через Alpine.morph
3. **Обрабатывает спецформаты** — htmlData, fields_values, redirects, toasts

Анализ исходного кода `vendor/moonshine/moonshine/src/UI/resources/js/Request/Core.js`:

```javascript
export default async function request(t, url, method, body, headers, componentRequestData) {
  // ... запрос через axios

  const {isAttachment, data, fileName} = await getResponseData(response, responseType)

  // beforeHandleResponse callback
  if (componentRequestData.hasBeforeHandleResponse()) {
    componentRequestData.beforeHandleResponse(data, t)
  }

  // responseHandler callback
  if (componentRequestData.hasResponseHandler()) {
    responseHandler(...)  // вызывает callback и return
    return  // <-- ВОТ ЗДЕСЬ!
  }

  // DOMUpdater для HTML
  DOMUpdater({htmlData, selectors, fields_values})

  // Toasts
  if (data.message) {
    MoonShine.ui.toast(data.message, type, data.messageDuration ?? null)
  }

  // Events dispatch
  if (events) {
    dispatchEvents(events, type, t, componentRequestData.extraProperties)
  }

  // НЕТ return data!
}
```

Функция возвращает `undefined` — только выполняет побочные эффекты.

## Root Cause

`listComponentRequest` предназначен для обновления **HTML списков** через Alpine.morph:

```javascript
// vendor/moonshine/moonshine/src/UI/resources/js/Request/Sets.js
export function listComponentRequest(component, pushState, after, prefix) {
  // ... подготовка URL

  let componentRequestData = new ComponentRequestData()
  componentRequestData
    .withBeforeHandleResponse(function (data, t) {
      // Обновление URL в браузере
      history.pushState({}, '', query ? '?' + query : location.pathname)

      // Обновление query parameters в ссылках
      document.querySelectorAll('.js-change-query').forEach(...)

      // Alpine.morph для обновления DOM
      let tempElement = document.createElement('div')
      tempElement.innerHTML = data
      Alpine.morph(t.$root, tempElement.firstElementChild.innerHTML, {...})

      t.loading = false
    })

  request(component, url, 'get', {}, {}, componentRequestData)
}
```

Это **не подходит** для FullCalendar, который:
1. Ожидает **callback-based API** (`successCallback(events)`)
2. Нужен **массив JSON-объектов**, а не HTML
3. Сам рендерит события через FullCalendar.js

## Solution

Используем **обычный fetch** с proper headers для MoonShine:

```javascript
fetchEvents: async function(info, successCallback, failureCallback) {
    this.loading = true;
    this.error = null;

    const start = info.start ? info.start.toISOString() : null;
    const end = info.end ? info.end.toISOString() : null;

    try {
        // Build URL with query parameters
        const url = new URL(this.endpoint, window.location.origin);
        if (start) url.searchParams.set('start', start);
        if (end) url.searchParams.set('end', end);

        // Prepare headers with CSRF token for MoonShine
        const headers = {
            'Accept': 'application/json',
            'Content-Type': 'application/json',
        };

        // Add CSRF token from meta tag
        const csrfToken = document.querySelector('meta[name="csrf-token"]')?.getAttribute('content');
        if (csrfToken) {
            headers['X-CSRF-TOKEN'] = csrfToken;
        }

        // Add X-Requested-With for AJAX detection
        headers['X-Requested-With'] = 'XMLHttpRequest';

        const response = await fetch(url.toString(), {
            method: 'GET',
            headers: headers
        });

        if (!response.ok) {
            throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }

        const data = await response.json();
        const events = Array.isArray(data) ? data : [];

        this.events = events;
        successCallback(events);  // <-- FullCalendar callback

    } catch (error) {
        this.error = error.message;
        if (failureCallback) {
            failureCallback(error);
        }
    } finally {
        this.loading = false;
    }
}
```

### Ключевые изменения:

1. **Убрана зависимость от MoonShine.request** — используем стандартный fetch
2. **Добавлен CSRF токен** — из `<meta name="csrf-token">`
3. **Добавлен X-Requested-With** — для корректной обработки AJAX на бэкенде
4. **Прямой возврат данных** — `events` передаётся в `successCallback`
5. **Убрана сложная логика** — нет async-проверок, fallback-ов

## Prevention

1. **Изучайте исходный код** — перед использованием чужих API читайте implementation
2. **Проверяйте return value** — если функция не возвращает данные, она не для данных
3. **Используйте правильные инструменты** — для JSON нужен fetch/axios, для HTML — MoonShine.request
4. **Читайте документацию** — MoonShine.request предназначен для компонентных обновлений
5. **Тестируйте callback-based API** — FullCalendar требует success/failure callbacks
