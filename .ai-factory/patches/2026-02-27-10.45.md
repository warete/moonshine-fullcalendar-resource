# Increased event fill and text contrast in calendar theme

**Date:** 2026-02-27 10:45
**Files:** resources/css/full-calendar.css, public/css/full-calendar.css
**Severity:** low

## Problem

Calendar events were visually too transparent after the theme rebase, and some event
text colors were too close to the background tint to stay readable across all semantic
variants.

## Root Cause

The initial reference-based port kept very light tonal fills (`16-20%`) and used raw
semantic token colors for text. That worked for stronger hues, but reduced contrast for
lighter tokens such as warning/info and made small event labels harder to read.

## Solution

Adjusted event styling to improve contrast while preserving the same tonal design:

- increased default and semantic event background fills
- mixed event text colors with the base text token so labels render darker
- gave custom accent events the same denser fill and darker text treatment
- rebuilt the published CSS asset

## Prevention

- After theme adjustments, manually verify event chips for all semantic colors, not just primary
- Avoid using pure semantic colors for event text on soft tinted backgrounds without a contrast mix
- Keep warning/info variants slightly darker than primary because those hues lose contrast faster
