# FullCalendar create modal closed immediately after grid click

**Date:** 2026-02-27 11:19
**Files:** src/Resources/FullCalendarResource.php, resources/js/full-calendar.js, tests/Feature/FullCalendarCreateConfigTest.php
**Severity:** medium

## Problem

После клика в свободной области календарного грида async create-модалка MoonShine открывалась только на долю секунды и сразу скрывалась.

## Root Cause

Для скрытого calendar-trigger использовался тот же `modalName`, что и для стандартной кнопки create ресурса (`resource-create-modal`). Это создавало конкурирующие modal responders с одинаковым событием toggle. Дополнительно trigger вызывался синхронно внутри того же click-цикла FullCalendar, что делало открытие чувствительным к UI race conditions в обработке клика.

## Solution

- Для grid-create trigger выделен отдельный modal event name: `resource-create-modal-calendar-grid`.
- Programmatic click по скрытому trigger перенесен на следующий tick через `setTimeout(..., 0)`, чтобы открыть модалку вне исходного click-цикла.
- Тест обновлен на новый `modalName` в resource config.

## Prevention

- Не использовать одинаковые MoonShine modal event names для разных teleported modal templates на одной странице.
- Для UI-открытия модалок из сторонних callback-ов (FullCalendar, Alpine custom handlers) выносить programmatic click/toggle на следующий event loop tick.
- Добавлять регрессионные проверки на repeated open/close и наличие нескольких modal responders с одинаковым именем.
