# FullCalendar grid click fired both select and dateClick

**Date:** 2026-02-27 11:25
**Files:** resources/js/full-calendar.js
**Severity:** medium

## Problem

После клика по свободной области day-grid create-модалка открывалась и почти сразу закрывалась, даже после разнесения modal names и отложенного programmatic click.

## Root Cause

На одном пользовательском действии FullCalendar вызывал сразу два callback-а: сначала `select`, затем `dateClick` для того же диапазона. Оба пути вызывали `openCreateModalFromGrid`, а скрытый trigger использует toggle-семантику модалки. Первый вызов открывал модалку, второй сразу закрывал ее тем же toggle-событием.

## Solution

Добавлен короткоживущий dedupe-guard по сигнатуре диапазона (`start`, `end`, `allDay`) с окном 500ms. Повторная попытка открыть ту же модалку для того же диапазона подавляется и логируется как `[FIX][create-from-grid] Duplicate create open suppressed`.

## Prevention

- Для FullCalendar нельзя предполагать, что `dateClick` и `select` взаимоисключающие.
- Любой UI flow, открывающий toggle-based modal из нескольких calendar callbacks, должен иметь dedupe/guard на один gesture.
- После frontend-изменений в пакете нужно не только `npm run build`, но и переопубликовывать vendor assets в host app перед browser-проверкой.
