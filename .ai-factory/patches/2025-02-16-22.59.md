# Контроллер возвращал события в неправильной структуре

**Date:** 2025-02-16 22:59
**Files:** src/Http/Controllers/FullCalendarEventsController.php
**Severity:** critical

## Problem

Контроллер возвращал JSON в формате `{'data': [...]}`, но FullCalendar ожидает просто массив событий.

**Неправильно:**
```json
{
  "data": [
    {"id": 1, "title": "Event", "start": "2025-02-16T10:00:00Z"},
    ...
  ]
}
```

**Правильно:**
```json
[
  {"id": 1, "title": "Event", "start": "2025-02-16T10:00:00Z"},
  ...
]
```

## Root Cause

В MoonShine обычно используется `JsonResponse::make(['data' => $items])` для стандартного CRUD API, но FullCalendar имеет свой собственный формат событий.

## Solution

Изменить контроллер чтобы возвращать массив напрямую:

```php
public function __invoke(CrudRequestContract $request): JsonResponse
{
    $resource = $request->getResource();

    abort_unless($resource instanceof FullCalendarResource, 404, 'FullCalendar resource not found');

    $events = $resource->getCalendarItems($request->all());

    return JsonResponse::make($events);  // <-- напрямую массив, не обёртывать в 'data'
}
```

## Prevention

1. **Изучайте документацию библиотек** — FullCalendar имеет свой формат данных
2. **Проверяйте API контракты** — что библиотека ожидает на входе
3. **Тестируйте вручную** — проверяйте JSON responses в браузере перед интеграцией
4. **Используйте type hints** — это помогает понять ожидаемый формат
