# Increased event text contrast while keeping accent hue

**Date:** 2026-02-27 10:58
**Files:** resources/css/full-calendar.css, public/css/full-calendar.css
**Severity:** low

## Problem

After increasing event fill opacity, labels inside event chips still felt too weak.
The text retained too much of the pure semantic hue and did not stand out enough
against the denser tinted backgrounds.

## Root Cause

Event text colors were still mixed too heavily toward accent colors. That preserved
the hue, but reduced perceived contrast, especially for warning, info, and custom
accent events where the background tint became stronger.

## Solution

Adjusted the text color mixes so labels lean further toward the base text token while
still retaining semantic color identity:

- reduced the accent share in default event text color
- reduced the accent share in all semantic event text overrides
- applied the same darker mix to custom accent events unless backend `textColor` is provided
- rebuilt the published CSS asset

## Prevention

- When increasing event background opacity, revisit text contrast in the same pass
- Treat `warning` and `info` as separate readability cases because they lose contrast earlier
- Keep backend `textColor` support as an override, but ensure CSS defaults are readable on their own
