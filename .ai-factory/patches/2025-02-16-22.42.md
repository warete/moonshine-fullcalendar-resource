# Wrong MoonShine.request signature used in API calls

**Date:** 2025-02-16 22:42
**Files:** resources/js/full-calendar.js
**Severity:** critical

## Problem

AJAX запрос для получения событий не работал, потому что использовалась неправильная сигнатура `MoonShine.request`.

Правильная сигнатура: `MoonShine.request(ctx, url, method, body, headers, data)`
Использовалось: `MoonShine.request(endpoint, {method, params})`

## Root Cause

В коде JavaScript вызов `MoonShine.request` использовали позиционные аргументы в объекте конфигурации, что не соответствует реальной сигнатуре функции.

Неправильно:
```javascript
window.MoonShine.request(this.endpoint, {
    method: 'GET',
    params: params
});
```

Правильно:
```javascript
window.MoonShine.request(
    this,  // ctx
    this.endpoint,  // url
    'GET',  // method
    null,  // body
    {},  // headers
    params  // data (query params)
);
```

## Solution

Исправлен вызов `MoonShine.request` в методе `fetchEvents`:
1. Передаём контекст Alpine компонента как первый параметр (`this`)
2. URL как второй параметр
3. HTTP метод как третий параметр
4. Query параметры через шестой параметр `data`

```javascript
const response = await window.MoonShine.request(
    this,  // ctx
    this.endpoint,  // url
    'GET',  // method
    null,  // body
    {},  // headers
    params  // data
);
```

## Prevention

1. **Проверяйте сигнатуры функций**: Всегда сверяйтесь с документацией или исходным кодом для правильного порядка аргументов
2. **Используйте TypeScript**: Для строго типизированных проектов это поможет выявить несоответствия на этапе компиляции
3. **Создайте типы**: Если MoonShine не предоставляет типы, создайте их локально для API
4. **Тестируйте API**: Добавляйте тесты для AJAX запросов чтобы убедиться что они работают корректно
5. **Читайте документацию**: Проверяйте moonshine.laravel.com для актуальной информации об API
