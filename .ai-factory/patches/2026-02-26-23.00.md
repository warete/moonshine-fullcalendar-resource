# Duplicate delete confirm modals from repeated teleported modal templates

**Date:** 2026-02-26 23:00
**Files:** resources/js/full-calendar.js
**Severity:** high

## Problem

Repeatedly opening the event dropdown and clicking the delete action caused multiple
confirm dialogs to appear at once (1 -> 3 -> 5/6 ...).

## Root Cause

MoonShine delete actions render a teleported modal template in the DOM (`.modal-template`)
that listens to a modal toggle browser event like:

`@modal_toggled:resource-delete-modal-113.window`

Each dropdown open re-initialized injected action HTML and created another teleported
modal template with the same modal event key. When delete was clicked, MoonShine
dispatched one toggle event and **all** duplicate modal templates opened.

## Solution

After Alpine initialization of injected dropdown action nodes:
- scan `document` for `.modal-template[data-teleport-target="true"]`
- group templates by their `@modal_toggled:*` event key
- remove duplicates, keeping only the latest template for each key

This prevents multiple confirm dialogs from responding to the same delete action.

## Prevention

- When integrating dynamic HTML with teleported modal components, deduplicate global
  teleported templates by event/name key after re-initialization
- Verify delete-confirm behavior across multiple open/close cycles, not only first click
- Use DevTools DOM inspection to compare visible modal count vs total teleported templates
